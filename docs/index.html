📋 新規LP作成 — 全ステップガイド

1
ページ仕様を追加
content/landing-pages.yaml を開き新規エントリーを追加。
必要項目: id slug title variant hero features faq legal
VS Code Explorer から content/landing-pages.yaml を選択、または Ctrl+P で検索
2
LP を生成（2ステップ）
LPカードの 「🔧 生成」 ボタンをクリック。
STEP 1: 表示される依頼文をコピー → Claude Code に貼り付けて送信
STEP 2: 生成完了後 bash scripts/post-generate.sh [page-id] をターミナルで実行
3
生成確認
右上 「🔄 更新」 をクリック。カードの pages/ ●（緑） を確認。
4
Staging に転送
「📤 Staging転送」 → ポップアップの手順で sync-page.yml を GitHub Actions で実行。完了後 _staging/ ●（緑）。
5
プレビューで確認
「👁 プレビュー」 でページを確認。
確認ポイント: ヘッドライン / CTAリンク / 実績数値+免責事項 / モバイル表示
6
承認 または 却下
✅ 承認: approve-page.yml → _approved/ にコピー → Netlify即時公開
✕ 却下: reject-page.yml（理由を入力）→ フィードバック保存 → STEP 2 で再生成
