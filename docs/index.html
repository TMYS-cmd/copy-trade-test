Generate LP を開く →

📋 新規LP作成 — 全ステップガイド

1
ページ仕様を追加
content/landing-pages.yaml を開き、新規ページのエントリーを追加します。
必要項目: id, slug, title, variant, hero, features, faq, legal
VS Code で開く: Explorer から content/landing-pages.yaml を選択
または Ctrl+P → ファイル名検索
2
LP を生成
カードの 「🔧 生成」 ボタンから実行します。2つの方法があります。
🌐 リモート実行（推奨）: GitHub Actions が自動でHTMLを生成。ターミナル操作不要。
※ 事前に ANTHROPIC_API_KEY シークレットの設定が必要
💻 ローカル実行: VS Codeターミナル（Ctrl+`）で
bash scripts/generate.sh [page-id] → Claude Code に依頼 → bash scripts/post-generate.sh [page-id]
3
ダッシュボードで生成確認
右上の 「🔄 更新」 ボタンをクリックしてデータを更新します。
LPカードの pages/ ●（緑） になっていることを確認してください。
4
Staging に転送
カードの 「📤 Staging転送」 ボタンをクリック。
ポップアップの手順に従って sync-page.yml を GitHub Actions で実行します。
完了後: _staging/ ●（緑） になります。
5
プレビューで確認
カードの 「👁 プレビュー」 ボタンでページを確認します。
確認ポイント: ヘッドライン文言 / CTAボタンリンク / 実績数値の免責事項 / モバイル表示 / 免責事項・リスク警告の有無
6
承認 または 却下
✅ 承認: 「✅ 承認」ボタン → approve-page.yml を実行 → _approved/ に自動コピー → Netlify即時公開
✕ 却下: 「✕ 却下」ボタン → reject-page.yml を実行（理由を入力） → フィードバックYAML保存 → STEP 2 に戻って再生成
