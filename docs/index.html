🔧 ページ生成（ローカル実行）

Gemini CLIはOAuth認証のため、ページ生成はPC上のターミナルで実行します。

① ターミナルでコマンドを実行：

bash scripts/generate.sh lp-001

② 実行完了後、このダッシュボードが自動更新されます（1分以内）。

※ Gemini CLIの初回認証: gemini を実行してGoogleアカウントでログイン
※ 実行ディレクトリ: C:\Users\kgtmy\Documents\copy-trade-core

⚙️ 初回セットアップ手順

GitHub Actions（sync/approve/reject）を有効にするために以下の設定が必要です。

1
Gemini CLI を認証（PC上で1回だけ）
PowerShellで gemini を実行 → ブラウザでGoogleアカウント認証
2
GitHub PAT（Personal Access Token）を作成
GitHub Settings > Tokens で repo スコープのTokenを作成する
3
copy-trade-core にシークレットを登録
Settings > Secrets > Actions で追加:
REPO_TOKEN = GitHub PAT（copy-trade-testへの書き込みに使用）
4
動作確認
「🔧 ページ生成」でローカル実行 → ダッシュボードにpages/が表示されたら
「📤 Staging転送」ワークフローを実行してテスト
