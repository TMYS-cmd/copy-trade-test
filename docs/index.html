📹 動画を自動再生するには？
ブラウザのセキュリティ上、動画を音声なし・自動で流すには以下の4つの属性が必要です。
これらがないとスマホ・Chromeでは止まってしまいます。
<video autoplay muted loop playsinline src="assets/hero.mp4"></video>
・autoplay — ページ読み込みと同時に再生
・muted — 音消し（これがないと自動再生できない）
・loop — 終わったら最初から繰り返す
・playsinline — iPhone で全画面にならず埋め込みで再生
・ファイルは assets/ フォルダに置いてください
⚡ ファイルサイズを減らすには？
無料ソフト HandBrake（handbrake.fr）で MP4 に変換・圧縮できます。
ループ動画は 5〜15秒・30MB以下が目安。Netlifyは1GB = 20クレジット消費します。
