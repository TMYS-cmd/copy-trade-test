「ドローダウン」とは、資産がピークから最大でどれだけ下落したかを示す指標です。多くのトレーダーが高収益を謳う一方で、一度の暴落で資金が半減・全滅するケースが後を絶ちません。

JPコピトレは最大でも-1.9%の損失に抑え、9ヶ月間一度もロスカット（強制決済による口座破綻）を起こしていません。
